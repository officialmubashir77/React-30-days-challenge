JavaScript Concepts in Hinglish

1. JavaScript Basics
JavaScript ek programming language hai jo websites ko interactive banati hai.

Simple samjho:
- HTML = structure
- CSS = design
- JavaScript = logic aur behavior

Example:
Agar user button par click kare aur message show ho, to yeh kaam JavaScript karta hai.

Example code:
let userName = "Ali";
console.log("Hello " + userName);

----------------------------------------

2. Variables and Constants

Variable:
Variable ek container hota hai jisme data store hota hai. Iski value change ho sakti hai.

Constant:
Constant bhi data store karta hai, lekin uski value change nahi hoti.

JavaScript me:
- let = change ho sakta hai
- const = change nahi hota

Example:
let age = 20;
console.log(age);

age = 21;
console.log(age);

const country = "Pakistan";
console.log(country);

Explanation:
- age change ho gaya kyun ke let use hua
- country change nahi hoga kyun ke const use hua

----------------------------------------

3. Loops

Loop ka matlab hota hai ek kaam ko baar baar repeat karna.

For loop example:
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

While loop example:
let count = 1;
while (count <= 3) {
  console.log(count);
  count++;
}

Explanation:
- for loop tab use hota hai jab repeat count pata ho
- while loop tab use hota hai jab condition ke basis par repeat karna ho

----------------------------------------

4. Conditions

Conditions decision making ke liye hoti hain.

Example:
let marks = 75;

if (marks >= 80) {
  console.log("Grade A");
} else if (marks >= 50) {
  console.log("Grade B");
} else {
  console.log("Fail");
}

Explanation:
- if pehli condition check karta hai
- else if doosri condition check karta hai
- else tab chalta hai jab koi bhi condition true na ho

----------------------------------------

5. Functions

Function reusable code block hota hai.
Ek baar function bana lo, phir usko baar baar use kar sakte ho.

Example:
function greet(name) {
  return "Hello " + name;
}

console.log(greet("Mubashir"));

function add(a, b) {
  return a + b;
}

console.log(add(10, 5));

Explanation:
- greet function name leta hai aur greeting return karta hai
- add function do numbers ko add karta hai

----------------------------------------

6. Local Storage

Local Storage browser me data save karta hai.
Browser band hone ke baad bhi data rehta hai.

Use cases:
- dark mode save karna
- cart items save karna
- username save karna

Browser example:
localStorage.setItem("theme", "dark");
let theme = localStorage.getItem("theme");
console.log(theme);

Important methods:
- setItem(key, value)
- getItem(key)
- removeItem(key)
- clear()

----------------------------------------

7. Session Storage

Session Storage bhi browser me data save karta hai,
lekin sirf current tab ya current session ke liye.

Tab band hua to data khatam.

Example:
sessionStorage.setItem("step", "2");
let currentStep = sessionStorage.getItem("step");
console.log(currentStep);

Difference:
- localStorage = long time tak
- sessionStorage = temporary

----------------------------------------

8. Cookies

Cookies browser me chhota data save karti hain.
Yeh login session, tracking, aur user preferences ke liye use hoti hain.

Example:
document.cookie = "username=Ali; expires=Fri, 31 Dec 2027 12:00:00 UTC; path=/";

Cookie dekhne ke liye:
console.log(document.cookie);

Explanation:
- cookie me chhota data hota hai
- expiry set ki ja sakti hai
- server ke sath bhi use hoti hai

----------------------------------------

9. HTTP Requests

HTTP Request ka matlab hai server se data lena ya bhejna.

Common types:
- GET = data lena
- POST = data bhejna
- PUT = data update karna
- DELETE = data delete karna

GET example:
fetch("https://jsonplaceholder.typicode.com/posts/1")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.log(error);
  });

POST example:
fetch("https://example.com/api/login", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    email: "test@gmail.com",
    password: "123456"
  })
});

Explanation:
- fetch request bhejta hai
- response.json data ko JSON me convert karta hai
- then success handle karta hai
- catch error handle karta hai
