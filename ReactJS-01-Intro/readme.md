## Simple explanation in easy words

### 1. React JS Pre-Requisite

This means the things you should learn **before starting React JS**.

#### JavaScript

React is based on JavaScript, so first you should know JavaScript basics.

#### Constants

Constants are values that do **not change**.
Example:

```js
const name = "Ali";
```

#### Variables

Variables store data that **can change**.
Example:

```js
let age = 20;
```

#### Loops

Loops repeat code again and again.
Example: printing numbers from 1 to 5.

#### Conditions

Conditions check something and make decisions.
Example:

```js
if (age > 18) {
  console.log("Adult");
}
```

#### Functions

Functions are blocks of code that do a task.
Example:

```js
function greet() {
  console.log("Hello");
}
```

#### Local Storage

Used to save data in browser for a long time.

#### Session Storage

Used to save data only for the current browser session.

#### Cookies

Small data saved in browser, often used for login or tracking.

#### HTTP Request

Used when your website sends or gets data from server or API.
