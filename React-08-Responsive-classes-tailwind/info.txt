If we don’t use Tailwind CSS and write all the CSS manually, it can take much more time to build a web page.

Tailwind CSS is a utility-first CSS framework that provides predefined classes for styling elements, which helps us build and design web pages faster. It is similar to Bootstrap in the sense that both provide ready-to-use CSS classes, but Tailwind gives us more flexibility and control over the design.

# Tailwind CSS Basic Notes

TAILWIND CSS COMPLETE NOTES / CHEAT SHEET
=========================================

Purpose:
- React + Vite + Tailwind CSS ke liye comprehensive utility-class reference.
- Tailwind me literally har possible class ki finite list nahi hoti, kyun ke arbitrary values
  (for example w-[347px], bg-[#123456], grid-cols-[200px_1fr]) aur custom theme values
  se unlimited utilities ban sakti hain.
- Is file me major/core utility families, common values, patterns, variants, responsive classes,
  states, dark mode, transforms, filters, forms, SVG, accessibility, etc. cover kiye gaye hain.

React note:
- HTML me: class="..."
- React/JSX me: className="..."

Example:
<div className="rounded-xl bg-blue-600 p-4 text-white shadow-lg">
  Hello
</div>

============================================================
183. IMPORTANT LEARNING RULES
============================================================

1. Tailwind mobile-first hai:
   base class pehle, phir sm:, md:, lg:, etc.

2. Repeated numeric values spacing scale follow karte hain:
   p-4 = 1rem / 16px by default.

3. Same color system bohat utilities me reuse hota hai:
   bg-blue-500
   text-blue-500
   border-blue-500
   ring-blue-500
   outline-blue-500
   fill-blue-500
   stroke-blue-500

4. Arbitrary value use kar sakte ho jab default scale enough na ho:
   w-[347px]
   bg-[#101827]
   grid-cols-[250px_1fr]

5. State variants prefix hoti hain:
   hover:bg-blue-600
   focus:ring-2
   disabled:opacity-50

6. Variants stack ho sakti hain:
   dark:md:hover:bg-blue-600

7. React me always className use karo:
   className="..."

8. Dynamic class names ko complete strings ki form me rakhna safer hota hai:
   Good:
   const colors = {
     blue: "bg-blue-500",
     red: "bg-red-500",
   }

   Avoid constructing incomplete utility fragments dynamically where Tailwind cannot
   detect the final class in source.
