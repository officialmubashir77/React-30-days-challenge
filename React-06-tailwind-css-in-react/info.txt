If we don’t use Tailwind CSS and write all the CSS manually, it can take much more time to build a web page.

Tailwind CSS is a utility-first CSS framework that provides predefined classes for styling elements, which helps us build and design web pages faster. It is similar to Bootstrap in the sense that both provide ready-to-use CSS classes, but Tailwind gives us more flexibility and control over the design.

## Padding

p-1   = padding all sides
p-2
p-3
p-4

pt-4  = padding-top
pr-4  = padding-right
pb-4  = padding-bottom
pl-4  = padding-left

px-4  = padding left + right
py-4  = padding top + bottom

Example:
<div class="px-4 py-2">
    Button
</div>

---

## Margin

m-4   = margin all sides

mt-4  = margin-top
mr-4  = margin-right
mb-4  = margin-bottom
ml-4  = margin-left

mx-4  = margin left + right
my-4  = margin top + bottom

mx-auto = horizontally center element

Example:
<div class="w-96 mx-auto">
    Center Div
</div>
